
# 📝 Character and Word Counter

A simple and responsive text analyzer built using HTML, CSS, and JavaScript.

## Features

- Live character count, including spaces.
- Character count excluding whitespace.
- Live word count.
- Sentence count based on sentence-ending punctuation.
- Clear text with one click.
- Responsive design for desktop and mobile.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Page structure
- `style.css` — Styling and responsive design
- `script.js` — Text counting logic and live updates

## How to Use

1. Type or paste text into the text area.
2. View the counts update automatically.
3. Click **Clear Text** to reset the text and counters.
